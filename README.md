⚽ G1 Robotics Soccer Sim in LuckyEngine
A robotics simulation project for LuckyEngine 2026.1.2, developed by LuckyRobots.
Two of the sharpest tools in the shed, G1 Red and G1 Blue attempt to whack the ball into the goal.

🧠 About the Project
This project simulates two G1 humanoid robots attempting to play soccer inside LuckyEngine, LuckyRobots' simulation environment. It was a short exploratory exercise to experiment with LuckyEngine, using a combination of LLM-assisted development and manual coding and configuration to see what could be achieved within a relatively short timeframe.

🎯 G1 Behaviours
 - Orient themselves and moves toward the ball.
 - Approaches along a curved trajectory, positioning itself on the far side of the ball relative to the goal.
 - Re-orients if its approach trajectory goes into a wall (Gets stuck).
 - Performs an arm swing to propel the ball toward the goal.
 - Rudimentary ball scoring.
